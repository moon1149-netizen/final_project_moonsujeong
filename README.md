markdown_v2_content = ♻️ 분리수거 도우미 (수원시 분리배출 가이드 웹앱)

자취를 시작하는 경기대생을 위해 사용자가 버리려는 물건에 맞는 올바른 배출 방법을 안내해 주는 Gradio 기반 웹 애플리케이션 프로토타입입니다. 사용자의 상황과 물건 상태를 다각도로 검증하여 수원시의 분리배출 규정을 기반으로 가장 최적의 자원 순환 및 폐기 방법을 제안합니다.

---

## 📌 주요 기능

### 1. 배출 방법 안내
* 사용자가 버리고 싶은 물건의 이름을 입력하면 분리 배출 방법을 정확하게 찾아줍니다.

### 2. 상황별 추가 검증 질문
* "단일 재질인가요?", "해당 물건을 분해할 수 있나요?" 등의 추가 질문을 제공합니다. 복합 재질 품목이거나 판단이 애매한 물건도 사용자의 구체적인 상황에 맞춰 가장 적합하고 정확한 배출 방법을 도출할 수 있도록 돕습니다.

### 3. 중고 거래 및 나눔 연계
* 무조건 폐기하는 대신 "혹시 아직 쓸만한가요?"라는 질문을 통해 물건의 재사용 가능 상태를 먼저 확인합니다. 상태가 양호하여 나눔이나 거래가 가능하다면 당근마켓 등 중고 거래 플랫폼으로 연계하여 자원 낭비를 줄이도록 유도합니다.

---

## 🛠️ 기술 스택 및 구성 환경

* **Language:** Python 3
* **UI Framework:** Gradio (Soft 테마 적용)
* **Execution Environment:** Google Colab / 웹 브라우저 호환
* **Data Source:** 수원시 분리배출 및 재활용 가이드 지침
